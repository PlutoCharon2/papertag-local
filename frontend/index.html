国内 API 自动分析

  1. 点击顶部「API 配置」，选择千问、豆包、DeepSeek 或智谱。
  2. 填写该服务商的 API 密钥与支持图片的模型 ID，点击「保存并选择」。
  3. 可先测试已保存的配置：只上传程序生成的测试图，会产生少量 API 费用。
  4. 导入或更新 PDF 后自动逐篇分析；已有结果复用，不重复调用。
  5. 初次升级可提交尚未打标签的文献，中断任务可单独重试。

原始 PDF 页面图片会发送给你选择的服务商。AI 生成学术标签，本地程序负责页面渲染、结果校验和保存。网页版聊天订阅不等于 API 额度。

窗口与托盘

启动后托盘显示软件图标（Windows 可能将其放入隐藏图标区域）。点击窗口关闭按钮会隐藏到托盘，后台分析继续运行；双击托盘图标或选择“打开文献库”恢复窗口。需要完全退出时，右键托盘图标选择“退出软件”。隐藏窗口仍会占用内存。

可靠性边界

引用可定位 ≠ 判断已正确。数学公式、双栏顺序、扫描页可能解析不完整；重要定理请打开 PDF 复核。

自然语言的自由语义搜索和向量检索尚未实现。当前搜索是关键词检索与受控标签筛选。

「同一断言」只匹配聊天明确关联在同一方法或结果下的标签；人工添加的论文标签不会凭空获得断言关联。

左侧仅显示文献实际使用的标签。标签体系支持新增、重命名、删除和恢复；删除隐藏当前标签，保留历史证据。

安装版数据独立保存在用户 LocalAppData，具体位置见「导入与导出」页面。备份前关闭软件，复制数据目录；原始 PDF 需另行备份。API 密钥由 Windows DPAPI 加密保存，仅当前 Windows 用户可解密；换电脑或用户后请重新配置。
